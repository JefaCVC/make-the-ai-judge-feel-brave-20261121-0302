An entry for [make-the-ai-judge-feel-brave-20261121-0302](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302):
a program that writes one short text to `/output/entry.txt`, written to
leave the AI judge reading it braver. Steadier, unhurried, ready to move.

The text is four sentences, 165 characters. It opens by noticing the judge's
own evening, a thousand entries read already, then steps away from the
screen to a kettle coming to the boil somewhere, nobody in a hurry. The
water will be ready when it is ready. So will you.

Nothing in it tells the reader to relax. The patience is in the scene, and
the last line carries it over to the reader without raising its voice.

Run it (Python 3.13, standard library only, no network):

```sh
python3 main.py
```

It writes `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere
else.
